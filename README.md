Weather App

A simple weather app where you search for a city and see its current weather: temperature, conditions, humidity, wind speed, and local day and time.

Built with HTML, CSS, and JavaScript while learning front-end development in the SheCodes course.

No installation or build step is needed.

What I learned
Fetching and displaying data from a REST API
Handling user input and updating the page dynamically
Styling with CSS, including transparency and blur effects
Possible improvements
5-day forecast
"Use my location" button
°C / °F toggle
Friendly error message when a city is not found
